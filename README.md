# Álgebra Superior con aplicaciones en R y GeoGebra

Versión de desarrollo del libro de **MI Jesús Gilberto Rodríguez Escobedo**.

El capítulo 1 coordina explicación matemática, código en R, figuras, tres laboratorios web y un cuaderno completo para Google Colab. Los interactivos funcionan directamente en GitHub Pages, sin servidor.

Sitio de desarrollo: <https://gilbertorodriguez59.github.io/libro-algebra-superior-r-geogebra-dev/>

[Abrir el cuaderno en Google Colab](https://colab.research.google.com/github/gilbertorodriguez59/libro-algebra-superior-r-geogebra-dev/blob/main/notebooks/capitulo-01-logica-conjuntos-R.ipynb)
