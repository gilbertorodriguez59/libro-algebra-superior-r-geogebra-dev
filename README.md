# Álgebra Superior con aplicaciones en R y GeoGebra

Versión de desarrollo del libro de **Jesús Gilberto Rodríguez Escobedo**.

Los capítulos 1 y 2 coordinan explicación matemática, código en R, figuras, laboratorios web y cuadernos completos para Google Colab. Los interactivos funcionan directamente en GitHub Pages, sin servidor. La versión incorpora índices temático, de figuras y de símbolos, además de referencias generales.

Sitio de desarrollo: <https://gilbertorodriguez59.github.io/libro-algebra-superior-r-geogebra-dev/>

[Abrir el cuaderno del capítulo 2 en Google Colab](https://colab.research.google.com/github/gilbertorodriguez59/libro-algebra-superior-r-geogebra-dev/blob/main/notebooks/capitulo-02-enteros-reales-R.ipynb)
