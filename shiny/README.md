# Laboratorios Shiny previstos para el capítulo 1

La primera versión del capítulo reserva este espacio para tres aplicaciones:

1. Constructor de tablas de verdad.
2. Laboratorio de conjuntos y diagramas de Venn.
3. Clasificador de funciones finitas.

Se desarrollarán después de aprobar el contenido matemático y los ejemplos de R, para evitar que la interfaz quede ligada a una versión todavía inestable del capítulo.
